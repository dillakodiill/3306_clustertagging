Peta interaktif untuk visualisasi cluster geotagging SE2026.

- Batas SLS
- Label Kecamatan | Desa | SLS
- Titik assignment

- Popup detail assignment dan SLS
- Filter enumerator
- Basemap Satellite dan OpenStreetMap
